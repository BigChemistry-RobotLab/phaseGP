phaseGP API Reference

Version 0.2.0

Changes in 0.2.0
  • Informed priors (MultiGPMeanModule, SKMultiGPMeanModule, and mean modules that wrap another PhaseGP) are now evaluated at the correct input locations when min_scale/max_scale are not 0/1 (inputs were previously scaled twice).
  • PhaseGP.fit trains on the 0/1 labels directly; the previous logit transformation of the labels was removed (epsilon is kept only for backward compatibility).
  • New SharpBernoulliLikelihood: labels are treated as certain measurements (likelihood_sharpness=6.0 by default).
  • PhaseTransferGP and SKPhaseTransferGP read the source weights with weight_readout_sharpness=1.0, the scale on which the weighting formulas were tuned.
  • SKMultiGPMeanModule maps scikit-learn probabilities to the latent space with the probit (inverse normal CDF) instead of the logit.
Results obtained with 0.2.0 differ numerically from those obtained with earlier versions.

models.py

Gaussian Process models for binary phase classification with active learning and transfer learning capabilities.

Classes

PhaseGP

Variational Gaussian Process model for binary phase classification.

PhaseGP(train_x, min_scale=None, max_scale=None, kernel_choice='matern32',
        lengthscale=0.3, learning_rate=0.1, training_iterations=120,
        lengthscale_interval=(0.2,0.3), outputscale_interval=(1.0,4.0),
        scale_inputs=True, device="cpu", likelihood_sharpness=6.0)
Parameter Type Default Description
train_x torch.Tensor required Initial training inputs used as inducing points, shape (n, d)
min_scale array-like None Minimum values for input scaling (0 if None)
max_scale array-like None Maximum values for input scaling (1 if None)
kernel_choice str 'matern32' Type of kernel: 'rbf', 'matern32', or 'matern52'
lengthscale float 0.3 Initial kernel lengthscale (in scaled [0,1] units)
learning_rate float 0.1 Optimization learning rate
training_iterations int 120 Number of training iterations
lengthscale_interval tuple (0.2, 0.3) Prior bounds for lengthscale parameter
outputscale_interval tuple (1.0, 4.0) Prior bounds for outputscale parameter
scale_inputs bool True Whether to internally scale the inputs to [0,1] using min_scale and max_scale
device str "cpu" Model's device ("cpu" or "cuda")
likelihood_sharpness float 6.0 Sharpness β of the probit link p(y=1|f) = Φ(β·f). Values > 1 treat the labels as certain measurements; 1.0 is the standard Bernoulli likelihood

Methods:

  • fit(train_x, train_y, epsilon=0.05, verbose=False) - Train the model on binary labels (0 or 1) using variational inference. epsilon is unused and kept for backward compatibility
  • predict(x) - Predict binary phase labels
  • predict_proba(x) - Predict the probability of phase 1
  • acquisition(x, sampled_points=None, epsilon=0.05, vanilla_acq=True, distance_acq=False, requires_grad=False) - Acquisition values σ(x) / (|μ(x)| + epsilon) for active learning. sampled_points, vanilla_acq and distance_acq are accepted for interface compatibility and are not used by this model
  • forward(x) - Forward pass through the GP model. The covariance module receives scaled inputs; the mean module receives inputs in their original units

PhaseTransferGP

Transfer Learning GP model for phase classification with multiple source models. Each source model has a weight model (a PhaseGP trained on whether the source predicts the measured labels correctly) that determines how much the source is trusted at each location.

PhaseTransferGP(source_model_list, train_x, min_scale=None, max_scale=None,
                prior_aggregation="linear", max_adaptive_power=5,
                explorative_threshold=0.4, kernel_choice='matern32',
                lengthscale=0.3, learning_rate=0.1, training_iterations=120,
                lengthscale_interval=(0.2,0.3), outputscale_interval=(1.0,4.0),
                scale_inputs=True, device="cpu", likelihood_sharpness=6.0,
                weight_readout_sharpness=1.0)

Additional parameters beyond PhaseGP:

Parameter Type Default Description
source_model_list list required List of pre-trained source models
prior_aggregation str 'linear' Method for aggregating priors: 'linear' or 'highest'
max_adaptive_power float 5 Maximum power for adaptive weighting
explorative_threshold float 0.4 Threshold for exploration vs exploitation (0 to 1)
likelihood_sharpness float 6.0 Sharpness of the probit link used to train all internal PhaseGPs (weight and target models)
weight_readout_sharpness float 1.0 Sharpness used to turn the weight models' latent function into source weights after training. The weight-dependent formulas (prior aggregation, adaptive power, explorative threshold) are tuned for 1.0

Methods:

  • fit(train_x, train_y, epsilon=0.05, verbose=False) - Train the weight models and the target model
  • predict(x) - Predict binary phase labels
  • predict_proba(x, return_all_data=False) - Predict phase probabilities using the weighted combination of source and target; with return_all_data=True also returns (source probabilities, target probabilities, weights)
  • get_weight(x, requires_grad=False) - Get the weight of the best source model at each input point
  • acquisition(x, sampled_points=None, epsilon=0.05, vanilla_acq=False, distance_acq=True, requires_grad=False) - Compute acquisition function for transfer learning; sampled_points is required when distance_acq=True
  • forward(x, return_all_data=False) - Forward pass combining source and target model predictions

SKPhaseTransferGP

Transfer Learning GP with scikit-learn compatible source models. Requires scikit-learn source models to have predict() and predict_proba() methods.

Inherits from PhaseTransferGP with the same parameters, except scale_inputs (always True). Source probabilities enter the prior through SKMultiGPMeanModule.

Methods:

  • chain_predict(x) - Binary prediction using the minimum of the ensemble and source probabilities

SharpBernoulliLikelihood

Bernoulli likelihood with a sharpened probit link, p(y=1|f) = Φ(sharpness · f). A sharpness above 1 makes a misclassified label very unlikely for a given latent value, so the labels are treated as certain measurements without inflating the latent scale. sharpness=1.0 is equivalent to gpytorch's BernoulliLikelihood.

SharpBernoulliLikelihood(sharpness=1.0)
Parameter Type Default Description
sharpness float 1.0 Fixed multiplier applied to the latent function in the probit link

priors.py

Informed prior mean functions for transfer learning. Source predictions in the latent space, weighted by their learned reliability, are used as the mean function of the target GP. Source and weight models are frozen (evaluation mode, no gradients).

Classes

MultiGPMeanModule

Prior mean from multiple GP source models. Used by PhaseTransferGP.

MultiGPMeanModule(source_model_list, weight_model_list, prior_aggregation="linear", device="cpu")
Parameter Type Default Description
source_model_list list required Pre-trained PhaseGP source models
weight_model_list list required PhaseGP weight models, one per source
prior_aggregation str 'linear' 'linear': Σᵢ μᵢ(x) · wᵢ(x)^(|μᵢ(x)|+1); 'highest': w(x) · μ(x) of the most reliable source
device str "cpu" Device where the prior is stored

SKMultiGPMeanModule

Prior mean from scikit-learn compatible source models. Used by SKPhaseTransferGP. Source probabilities p are mapped to the latent space with the probit transformation f = Φ⁻¹(clamp(p, ε, 1−ε)), matching the probit likelihood of the target GP; the aggregation methods are the same as in MultiGPMeanModule.

SKMultiGPMeanModule(source_model_list, weight_model_list, prior_aggregation="linear", epsilon=0.05, device="cpu")
Parameter Type Default Description
source_model_list list required scikit-learn compatible source models
weight_model_list list required PhaseGP weight models, one per source
prior_aggregation str 'linear' Aggregation method: 'linear' or 'highest'
epsilon float 0.05 Clamping value for the probit transformation (latent values within about ±1.64)
device str "cpu" Device where the prior is stored

GPMeanModule

Prior mean from a single GP source model: μ_source(x) · w(x). Not used by the transfer models; MultiGPMeanModule with one source behaves similarly.

GPMeanModule(source_model, weight_model)
